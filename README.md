# Chatbot-Ai-Api
# AI Chatbot Using Hugging Face API

An AI-powered chatbot built using the Hugging Face API that allows users to interact with an AI model and receive intelligent responses in real time.

## Features
- AI-powered conversations
- Integration with Hugging Face API
- Real-time responses
- User-friendly interface
- Interactive chatbot experience

## Tech Stack
- Frontend: React.js
- AI: Hugging Face API
- Language: JavaScript

## Installation

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:
   ```bash
   cd your-project-folder
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Configure your Hugging Face API token in the `.env` file.

5. Start the development server:
   ```bash
   npm run dev
   ```

## Environment Variables

```env
VITE_HUGGINGFACE_API_KEY=your_api_key
```

**Note:** Never upload your API key or `.env` file to GitHub.
